---

### 1. Постановка задачи
* **Объект проектирования:** Веб-система учета успеваемости и посещаемости студентов группы.
* **Исходные проблемы:**
  * Ручной учет в бумажных журналах;
  * Риск утери или повреждения данных;
  * Отсутствие оперативного доступа к оценкам для студентов и родителей;
  * Высокая трудоемкость сбора итоговой статистики и формирования отчетов.
* **Основные функции системы:**
  * Авторизация и разграничение прав доступа (Студент, Преподаватель, Администратор);
  * Ведение учета посещаемости и выставление оценок за занятия;
  * Автоматический расчет среднего балла по предметам;
  * Формирование итоговых ведомостей и отчетов по успеваемости.
* **Ожидаемый результат:** Повышение прозрачности учета успеваемости, автоматизация рутинных процессов формирования отчетности и снижение количества ошибок при расчете итоговых показателей.

---

### 2. Выбор платформы реализации
* **Выбранное решение:** Веб-платформа (Кроссплатформенное приложение).
* **Обоснование выбора:**
  * **Доступность:** Работает через любой современный браузер на любых устройствах (ПК, ноутбуки, планшеты, смартфоны);
  * **Простота поддержки:** Централизованное обновление на сервере без необходимости установки ПО на каждое рабочее место;
  * **Удобство использования:** Единый интерфейс для преподавателей и студентов.
